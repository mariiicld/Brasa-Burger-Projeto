# Brasa Burger — Site de Hamburgueria

## 1. Apresentação do projeto

O Brasa Burger é um projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Front-End para Web, com o objetivo de criar um site institucional para uma hamburgueria fictícia.

O site foi planejado para apresentar a identidade da hamburgueria, divulgar seu cardápio, mostrar seu ambiente, disponibilizar informações sobre eventos e facilitar o contato com os visitantes.

A proposta é oferecer uma experiência de navegação simples, organizada e acessível, permitindo que os usuários encontrem facilmente as informações sobre o estabelecimento.

## 2. Objetivo do site

Desenvolver uma plataforma digital para apresentar a hamburgueria Brasa Burger, disponibilizando informações sobre seus produtos, ambiente, localização, programação e formas de contato.

O projeto também considera a utilização de um QR Code no estabelecimento, permitindo que os clientes acessem o cardápio digital para consulta. Os pedidos presenciais são realizados diretamente com os funcionários, sem sistema de compras ou delivery online integrado ao site.

## 3. Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo das páginas.
- **CSS3:** estilização e identidade visual.
- **JavaScript:** implementação de interações, recursos de acessibilidade e funcionalidades do menu.

## 4. Páginas do projeto

O site é composto por dez páginas HTML interligadas:

1. `index.html` — página inicial.
2. `sobre.html` — apresentação da hamburgueria.
3. `cardapio.html` — apresentação do cardápio.
4. `ambiente.html` — apresentação do ambiente.
5. `eventos.html` — informações sobre eventos.
6. `agenda.html` — programação da hamburgueria.
7. `localizacao.html` — informações de localização e funcionamento.
8. `faq.html` — perguntas frequentes.
9. `contato.html` — informações e formulário de contato.
10. `orcamento.html` — formulário para solicitação de orçamento de eventos.

## 5. Recursos e funcionalidades

O projeto contempla:

- Navegação entre as páginas por meio de menu.
- Apresentação dos produtos e informações da hamburgueria.
- Formulários de contato e solicitação de orçamento.
- Modo escuro.
- Ajuste do tamanho da fonte.
- Menu adaptado para dispositivos móveis.
- Organização de conteúdo e recursos visuais.
- Acesso ao cardápio por QR Code.

## 7. Como executar o projeto

1. Baixar ou clonar o repositório.
2. Extrair os arquivos, caso estejam compactados.
3. Manter a organização original das pastas.
4. Abrir o arquivo `index.html` em um navegador.
5. Para facilitar o desenvolvimento e os testes, recomenda-se utilizar o Visual Studio Code com a extensão Live Server.
